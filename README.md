# Simple Bank System (C++)

A robust console-based Banking Management System developed in C++. This project was built as part of the Algorithms & Problem Solving Level 3 (Course 7) curriculum from Programming Advices, focusing on algorithmic thinking, structured programming, and file handling.

---

## 🚀 Features

- Show Client List: Displays formatted tabular records of all bank clients.
- Add New Client: Registers new accounts with validation to prevent duplicate Account Numbers.
- Find Client: Quick search functionality by Account Number.
- Update Client Info: Modifies existing client records (Name, Phone, Pin Code, Balance).
- Delete Client: Safely removes an existing account from the system.
- Data Persistence: All transactions and account data are saved directly to a flat file (Clients.txt).

---

## 🛠️ Key Concepts Applied

- **Structures (struct):** Representing client records and transactional data.
- **Vectors (std::vector):** Dynamic in-memory data manipulation.
- **File Streams (fstream):** Reading, parsing, writing, and persisting data.
- String Manipulation: Delimiter-based record parsing and string formatting.
- Modular Programming: Clean separation of concerns through functional decomposition.
